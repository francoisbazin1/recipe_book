      HOW IT WENT

      MADE ON

      READING RECIPES FROM PHOTOS

      This is what lets the app read a photo of a recipe and write it out for you. Without it you can still type recipes in, and still add ones people send you. The key lives on this phone only. Each recipe read costs a couple of cents.

      SOMEONE SENT ME A RECIPE

      Tapping the link they sent usually does it on its own. Use this box if tapping it did nothing, which happens on an iPhone when the app is on the home screen.

      KEEPING IT SAFE

      Everything lives on this phone. Save a copy now and then, and definitely before changing phones. It saves one file with everything in it, photos included. Bringing a copy back can add to what is already here rather than replacing it, so nothing gets lost. The backup includes the photos so the file can be large.

      ABOUT

      Tap the title at the top to call it whatever you like, name and line underneath. Add to Home Screen from the browser menu and it opens like a normal app, offline and all.
